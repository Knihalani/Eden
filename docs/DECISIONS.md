# Decisions

Numbered, dated, never renumbered. A later decision that reverses one says so and links back. When code and this
file disagree, fix one of them in the same change.

| D1 | 2026-10-27 | Target personal and proactive agents built by tenants, not coding agents. | Founder's call. Coding-agent read tools are high-frequency and directly reachable by the agent; different economics. |
| D2 | 2026-10-27 | The partner both answers (`ask`) and injects unasked (`observe`). | A subagent only answers, so it inherits the agent's not-knowing-what-to-ask problem. |

| D28 | 2026-10-28 | A query planner chooses what each lookup sends to each connector (`QueryPlanner`, `PlannedSource`). It chooses among query shapes: the cue's terms, its entities, one call per entity, an entity plus the rarest term, and quoted entities where an operator says the connector takes phrases. It learns per (tenant, user, connector, cue with or without an entity) with one `BetaBandit` each, rewarded at once by how much of the cue the best returned item covers, and tries one other shape when the first returns nothing. It is conservative: the cue's terms (what Eden sent before) are the incumbent, kept unless another shape's posterior mean beats them by 0.1. Shapes drop all search syntax from untrusted text. State is content-free counts, in memory and in the source map, both cleared by `forget`. Every extra call takes its own rate token (`SourceFanout.permit`). Traces carry shape names and call counts only. Opt-in (`PartnerDeps.planner`, `EDEN_QUERY_PLANNER=1`). Departures from the plan: no new `ContextualBandit` primitive, no capability probe (the cascade and the incumbent learn from real lookups), immediate reward only. When a search tool has no `args` function, `McpSource` maps the call from its input schema plus operator-fixed values, and refuses a schema it cannot map rather than guessing. | docs/research/query-planner-results.md. Simulation, held-out connectors: recall 9.0% to 17.6% with no model, and 14.8% to 39.6% with a perfect judge; false fires unchanged; about 50% more source calls. Real servers in the connector lab: where the terms reached 0% (6 configurations), 23–70%; Basic Memory 63% to 72%; Meilisearch 30% to 62%; within noise of today's on OR and vector search, where plain Thompson sampling lost 9–11 points. Off by default: the call cost fails the plan's tier-2 gate, and shadow runs on consenting accounts have not happened. |
