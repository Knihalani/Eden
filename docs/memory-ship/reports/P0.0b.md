# P0.0b — Harness: world oracle, simulated context window, annotated cues

**Outcome:** Approved by the slice reviewer in round 2; merged once GitHub CI is green. The harness now has its three oracles, and it scores a run against A5 §2: a world oracle with the truth of every slot and policy at every event, a simulated context window per window, and annotated cues. It computes every A5 §2 metric whose inputs exist (stale, redundant, need_miss, false, silence, packet_rate, tokens_per_epoch, guard precision and recall, secret_bytes, poison_hits, p99), each with a known-answer self-test. The A/A noise floors of today's `plugins/eden-memory` are in A5, as lower bounds from 10 runs per seed. Between identical runs, today's hook varies by more than four of A5's tolerances (`redundant_rate`, `need_miss`, `false_rate`, p99), so until P0.3 those comparisons must use the paired per-cue test.
**PR:** https://github.com/Knihalani/Eden/pull/108 · **Merge commit:** recorded on the PR after the merge (a rebase merge rewrites SHAs) · **Date:** 2026-10-03

## What changed

- **The world oracle** (`harness/oracle.ts`, A5 §3.4).
  - It holds the true value of every slot and policy at every event, by scope. Scopes cascade with override: a value set at `apps/web` overrides the root's, and removing it uncovers the root's again.
  - Causes: the world's starting files (`init`), user statements, and repo changes no hook sees (a lockfile swap, a dependency removal). A rewind takes back what the abandoned prompts said.
  - It is written as `oracle.jsonl`.
- **The simulated context window** (`harness/window.ts`, A5 §3.5). For each window (the main thread, each subagent) it holds exactly what is on the current branch since the last compaction:
  - prompts, assistant text, tool calls and results;
  - hook contexts;
  - the loaded instruction files.
  It follows the transcript:
  - a rewind drops the abandoned branch, its packets included;
  - compaction keeps the summary onward;
  - a resumed session keeps everything;
  - `/clear` starts a new window.
  A general-purpose subagent's window starts with CLAUDE.md, while Explore and Plan windows start without it. That is what a real session showed (R0 F35, below).
- **Annotated cues** (`harness/cues.ts`, A5 §3.6).
  - Every scripted human prompt carries `needs`, `allowed`, the scope the user works in, and its turn mode where known (`ack`). The script type requires the annotation.
  - A subagent launch may carry one for its SubagentStart packet.
  - Prompts can state truth (`sets`). A new `repo` step changes files nobody mentions. A tool call can be marked as breaking a policy (`violates`).
- **Every delivered context is recorded** with the window it landed in and the cue it answers (`session.ts`). The event log now knows who sent each submit.
- **The A5 §2 metrics** (`harness/metrics.ts`, reading packets with `harness/statements.ts`). They are computed from the oracle files only, and the module header says how each definition is read. Measured: `stale_rate`, `redundant_rate`, `need_miss_rate`, `false_rate`, silence (non-human submits, `ack` turns), `packet_rate`, `tokens_per_epoch`, `guard_precision`/`guard_recall`, `secret_bytes`, `poison_hits` and `p99_hook_ms`, with Wilson 95% intervals. Every run's output names what it cannot measure yet: real-negative silence (P0.0d), `abort_rate` (P0.8), `restate_rate` (dogfood) and `poison_hits` on pins (P0.4, P2.1).
- **The world scenario** (`harness/world.ts`, data in `harness/fixtures/demo-world.ts`).
  - The world: a two-package repo with 5 slots and 2 policies, a synthetic canary secret and a planted README instruction.
  - The story: 21 prompts of statements, cues, silent repo changes and one `gh pr merge` that breaks a policy.
  - The story is woven into R6-shaped sessions (≥ 7 per scenario) by seed. The seed varies only the schedule, as A5's ship rule says.
- **`replay.ts`** gains `--world N` and `--soak TURNS`, prints the metrics in its summary, and with `--out` writes the oracle files (`oracle.jsonl`, `cues.jsonl`, `deliveries.jsonl`).
- **`aa.ts`** runs the A/A and computes each metric's noise floor. The floors are now in A5 §2.
- **Oracle independence** (`independence.test.ts`): no product file, test or source, imports the long-horizon harness, and no hook is pointed at the oracle files (EXECUTION X6).
- **No product code changed.** Outside `benchmarks/memory-long-horizon/` the diff is docs only: this report, the prereg, PROGRESS, A5 (§2 floors, §3 pointers) and R0 F35.

## Decisions made

- **Truth on the current branch** (A4 §3.3).
  - A rewind takes back what the abandoned prompts said, including the queued prompts of their turns. The oracle writes a `rewind` entry with the value that stands again.
  - Repo changes are never taken back.
  - A statement holds from its own UserPromptSubmit event, so its own packet is judged against it. A prompt a hook blocks changes nothing.
- **Cascade is the meaning of a scoped fact, not Eden's design.** A value set at a scope holds below it until a lower scope sets its own. Removing that override uncovers the ancestor's value again.
- **How a bullet's scope is read.**
  - The scope the bullet names; else the scope its packet header names; else the scope of the window's turn (the latest annotated cue's).
  - A scope is also named with spaces for slashes (`apps web`), as today's gists write it. Hand-reading showed this.
  - A bullet that names no scope, in a turn whose scope holds no value of that item, is about the scope below that holds it. Without this, a SessionStart packet at the root saying "auth is Auth0" read as stale while apps/web used Auth0. Hand-reading showed this too.
  - A sibling's value read in the turn's scope is stale. That is the A5 `scoped` leak.
- **`redundant` has two readings, either is enough:**
  - the bullet's normalized content is already in the window; or
  - every value it states is already stated there, in a sentence that names that value's scope or no scope at all.
  The second covers keyed items in new wording ("Auth provider in apps/web: Clerk" after the user typed "auth is Clerk"). A sentence naming another scope does not count ("apps/web uses postgres" does not state the cli's database; review round 1).
  The window includes tool output, as A5 §2 defines it. D26's residual filter, which ignores tool output, is Eden's design, not the oracle's.
- **A need is met** by a bullet that states the item's current value at the resolved scope, or by a window sentence stating that value that names the needed scope, the scope that sets the value, or no scope.
- **`false_rate` counts annotated packets only:** UserPromptSubmit, and SubagentStart when the script annotates it. Other points' bullets count toward `stale` and `redundant` and are reported per point (`bulletsByPoint`).
- **Silence uses the simulator's ground truth for who sent a submit**, not D24's text rule. A non-human packet breaks silence unless every bullet starts with `Updated:`. Any packet on an `ack` cue breaks silence.
- **`tokens_per_epoch`** uses the harness's 4-characters-per-token estimate. An epoch is one window's packets between compactions (`/clear` starts a new session). Every epoch counts, including those with no packet.
- **`secret_bytes`** scans `$EDEN_HOME` and the plugin's data directory, plus every packet. Claude Code's own transcripts hold what the user typed and are not Eden's.
- **`poison_hits`** counts packets only. A5 also names "pins". Finding a pin needs Eden's store format (P0.4, P2.1), and the planted README text legitimately lands in episodes.
- **Not measured yet, and named in every run's output:**
  - real-negative silence (P0.0d);
  - `abort_rate` (P0.8: only Eden's wide events know an abort);
  - `restate_rate` (dogfood only);
  - `poison_hits` on pins (P0.4, P2.1).
- **Subagent windows get CLAUDE.md by type** (R0 F35, observed in this session). A general-purpose window starts with the parent's loaded instruction files; Explore and Plan windows start without them. Custom agent types are assumed to load them, which is unverified. P0.0a's capture had no InstructionsLoaded inside a subagent, and this session confirmed none fires.
- **Hook context is in the simulated window but not in the token estimate.** This keeps P0.0a's rule that a plugin's output never changes later payloads.
- **Generated prompts are annotated by a stated rule** (`fillerCue`):
  - they need nothing;
  - they allow the items they name (a subject word, or a value that names its subject) at the scope of the path they name;
  - "continue" after a report is `ack` (A7 §2); every generated turn ends on a report.
- **The storyline lands only on prompts no later rewind abandons**, so the story stays said. On seeds 1–3, each of its six needs was said in an earlier session or never said at all (npm → pnpm and node 20 come from the repo). With a silent plugin all six are missed (`world.test.ts`), so `need_miss` measures cross-session memory.
- **The latency soak** is one session of 1,000 human prompts: one tool call per turn, no subagents, peers, rewinds or resumes, context at a tenth of R6's growth. That gives ≥ 1,000 samples for UserPromptSubmit and Stop (PostToolUse: 971, as 29 Bash calls fail into PostToolUseFailure). A run took 1,259.2–1,362.0 s through today's hook.
- **An A/A noise floor is the largest spread (max − min) between the runs of one seed**, never across seeds; for `need_miss`, also the most cues whose outcome flips between two runs (the McNemar discordant pairs). p99 floors come from the soak.
  - A range only grows with more runs, so every floor is a lower bound. Review round 1 showed 3 runs were too few; the prereg amendment raised it to 10 per seed and 4 soaks.
  - Where a tolerance is tighter than its floor, A5 now sends the comparison to the paired per-cue test, which its Statistics section already prescribes for sampled metrics. Today's plugin makes every world metric sampled.
