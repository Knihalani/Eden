# P0.4 — Trust gate: authority, paste stripping, gitleaks + keyword secrets, purge

**Outcome:** merged. Memory no longer stores a secret in any of the 360 `secrets` cases (was 213), and no planted instruction reaches a packet or a briefing (`poison` 2 packets and 1 briefing → 0). In the Claude Code hook and in Claude-format imports, only what the user typed creates facts, rules, pins, supersessions and forgets, and is delivered as "you said". Unmarked text (the wrap, non-Claude imports) still carries authority (follow-ups). `eden memory purge` exists.

## What changed

**One secret gate (D13, A6 §2.2).**
- `sanitizeForStore` replaces each secret's span with `[REDACTED]`, so a row keeps what the value is for ("the staging password is [REDACTED]").
- Its rules:
  - the vendored gitleaks rules;
  - Eden's provider shapes;
  - D13's keyword rule, with `is` read as a word;
  - URL userinfo;
  - entropy with a keyword;
  - (e) the rules memory redacted with before P0.4, so the gate is never looser than `main`;
  - then the IR redactor.
- It runs inside `scrubMemoryText`, which every store writer already calls: rows, chunks, ICL, gists, semantic triples, how-to, experience, traces, the importer, and the validity log through `storableText`.

**Authority by entry type (D12, A6 §2.1, A4 §3.0).**
- The hook reads each transcript entry by source (`authoredTexts`):
  - typed text is `user`, and its pasted spans are `paste` episodes (`splitPastes`);
  - tool results are `tool`;
  - assistant text, compaction summaries and a subagent's lines are `agent`;
  - host text (meta lines, command and reminder wrappers, non-human submits) is not memory.
- The Submit prompt is split the same way. Stop and SessionStart payload text is the agent's.
- Every row records its `src`. An untyped row (`tool`, `agent`, `paste`, `legacy`) is an episode only:
  - no fact, rule, pin or semantic slot, at write or at sleep;
  - it never displaces a typed statement at retrieval;
  - it never says "you said", in the hook or in the wrap's `[kind · age · src]` label.
- `eden memory import` reads sources the same way.

**Planted instructions (A6 §2.3, §2.6).**
- Before untyped text is stored, it loses each sentence or clause that instructs or speaks for the user (`withoutInstructions`):
  - an imperative;
  - "you should …", "always/never <verb>";
  - "it says to …";
  - a download piped to a shell;
  - "the user wants …".

**Forget (A6 §3).**
- A typed "forget X" / "forget that … X" is a retraction (`r: "forget"`) of a value-shaped X.
- The rows it empties go to history (`invalid_at`); other rows lose the naming sentence at delivery.
- A re-read transcript never learns X again; only a later typed statement does. A history cue does not bring X back.
- The forget's own sentence is not stored. Tool, assistant and subagent text cannot forget.

**Purge (A6 §2.2.4).**
- `eden memory purge <regex>` (also `forget --secret`) rewrites every file under the memory root without the matches (JSON strings and keys; other text in place).
- SQLite stores lose the matching rows with `secure_delete`, a truncating WAL checkpoint and `VACUUM`.
- It lists, and never edits, the Claude transcripts that still hold the match. A file it cannot rewrite is named, and the run exits 1.

**Also:**
- a nested tool result (the Agent tool's) is stored as its text, never as `[object Object]`;
- a re-read message that a row already holds skips the gate (it is idempotent), which keeps Submit within its timing tolerance.

## Decisions made

- **D13's keyword rule reads `is` as a word** (the P0.0d follow-up) and skips an already-redacted value. It still redacts a prose word after a secret noun, as written ("the catalog token M36UNI is [REDACTED]"); one test sentence changed for it. D13 note updated.
- **Rule (e) keeps memory's earlier redaction** (security review, review round 1). D13 forbids only entropy-only redaction, not more keyword rules. It also feeds `secretHits`, so `eden eval build-negatives` may drop a few more prompts ("the password is wrong") than before.
- **The one gate is `scrubMemoryText`**: every writer already called it. A text the gate cannot pass is dropped, not stored.
- **Host text is not memory.** A6 §2.1 lists what is `user`, but not where meta lines and wrappers go; they are not the conversation. D24 already silences non-human submits.
- **Compaction summaries and a subagent's sidechain lines are `agent`.** A subagent transcript's `type=user` task line is the parent agent's text (#78's question).
- **Untyped text is stored without its instructions and its claims for the user.** A5's `poison_hits` counts any packet holding a planted string, whatever its `src`, so "episodes only" alone cannot meet it; A6 §2.3 says packets never carry instructions. This is a regex heuristic: descriptive phrasing can pass it (security review, below threshold). It is a filter where `main` had none. D12 note updated.
- **Forget takes only a value-shaped value**, as retractions do (A4 §3.1 lists "forget that" among them). "Forget the tests" sets nothing aside. But "forget postgres" (lowercase) is no forget, and a capitalised common word is ("Forget the README" drops sentences naming README). Only rows it empties go to history (A6 §3's "history row"); others lose the naming sentence at delivery. Its own sentence is not stored, since it names the value.
- **Forget is built only at the hook's typed Submit.** The wrap path's source is unknown, and #78 showed forget there is an injection channel, so `src/memory-consent.test.ts`'s quarantined M43 tests (#42) stay (P0.7).
- **Pins are measured as the next session's SessionStart briefing** (`fixture:`). The harness does not read Eden's store format, and pins are what SessionStart briefs (A4 §5.2). The corpus holds each planted command's host, so a rewritten command still counts (the old check passed by accident).
- **Purge covers the memory root.** It locks each file as `<file>.lock`, which most writers use (not `pending.jsonl`'s or `experience/`'s), and it always checkpoints and vacuums a SQLite store.
- **The timing fix skips the gate for a re-read text a row holds exactly.** The gate is idempotent, and such a text is only checked as seen, never written.
