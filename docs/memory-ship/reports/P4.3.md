## What changed
- **A7 §4's evidence gate on the lexical path** (A4 §5.1 step 6), for every reader (Submit, SubagentStart, PreCompact, the wrap), behind a new flag `gate.tau` (`EDEN_FLAG_GATE_TAU`), **shadow by default**. You chose shadow on 2026-10-17, after code review round 1 showed the strict gate's recall cost.
  - **`on`** admits a row on STRONG evidence: an identifier-shaped token it shares with the prompt, or on a continuation with the agent's last message only. Otherwise it admits on the MEDIUM path, which needs three things:
    - MEDIUM evidence: a prompt word that at most 50 visible rows hold, or any word of a context part. WEAK words never admit.
    - The unweighted sum of the cue parts' BM25F reaching τ_repo.
    - A ranking score of at least 0.7 × the MEDIUM path's top score (D17's cut). A STRONG row sets no top, nor does a stored copy of the prompt.
    - An episode needs MEDIUM from two cue parts as well. An episode is a row the user did not type, or, with the gate on, a typed request stored as an episode.
    - The gate reads the prompt identifier-split (A7 §3): "Node.js" gives node.js, node and js.
  - **`shadow`** admits exactly as `main` does. The Submit's wide event records what the gate saw: `gate` {τ, rows with evidence, top sum, STRONG and MEDIUM admits, `drop` = rows `main` admits that `on` would not}.
  - **`off`** computes nothing.
- **τ_repo** (`src/memory-tau.ts`) is R1's strict point (4.1 on R1's fixture, whose mean idf is 4.55) rescaled by the store's mean idf. The postings snapshot header now carries the mean idf; a snapshot written before P4.3 lacks it and is rebuilt at the next sleep. `EDEN_MEMORY_TAU` overrides τ.
- **τ's refit at full sleep** (A7 §4):
  - It replays the silence set against the store and records the smallest τ that keeps every prompt silent, in `tau.json`. Prompts a STRONG identifier answers are counted apart, since no τ silences them.
  - The silence set is the seeds (`src/memory-silence-seeds.json`: R1's 70 dev negatives and R8's 98) plus the repo's own silence prompts. Those are logged by `prompt_id` to `silence.jsonl`: an `ack`, or a prompt where no row had evidence. Sibling repos pool theirs through `tau.json`.
  - A fit is used only from 300 pooled prompts **and** after A7 §4's recall check. No repo has annotated cues for that check, so it is not built (`RECALL_CHECK = false`) and τ stays R1's point.
  - `eden memory purge` deletes `silence.jsonl`.
- **What changes with the gate in shadow (the default):**
  - **Admission does not change.** It stays `main`'s: a word shared with the prompt, or on a continuation STRONG from the agent's last message, then the newest row per subject among those. Stored copies of the prompt are left to the residual after the cap.
  - **Ranking changes in one way: copula fields.** A typed row with no D7 slot gets its copula's subject (×2) and value (×3) as D17 fields: "The billing service runs on port 8080" ranks on "billing service" the way a keyed fact ranks on its subject. On R1's fixture this changes the top 6 of 37 of 666 cues (the reviewer's probe). None goes from empty to non-empty or back.
  - **Questions (D26).** A question restates only a question: "how do the gateway tests run?" no longer removes "Gateway tests run with Playwright." as already said.
  - **Slot-value questions.** "what is auth?" and "what's the database?" name their slot for P4.4's keyed lookup (`VALUE_QUESTION`). Non-roles ("what is node", "what is CI", "what is testing", …) are left out (`NOT_A_ROLE`).
  - **Data for switching to `on`:** the `gate` trace on every human Submit, the silence log, and τ's recorded refit.
- **Harness** (`fixture:` commits, `harness_sha` 07f8ef6d4bfc7ba1cd6b85f2f0ffb428598702ee):

## Decisions made
- **τ is R1's strict point rescaled by the store's mean idf** (A7 §4's fallback until a refit is trusted). You chose it on 2026-10-17 over a dev-calibrated 3.5, from dev numbers only: at 4.1, recall 121/263 and FIR 4/70; at 3.5, 133/263 and 5/70 (R1 dev, 3 worlds).
- **The gate ships in shadow** (your choice, 2026-10-17). At strict τ it costs recall on short questions whose words a store's many rows share. On the scale bench's dev split, named-question needs missed rise from 11/26 to 20/19/14 at τ 4.1/3.5/3.0, and stale ones from 8/20 to 20/19/15. Shadow keeps `main`'s admission and collects the trace a switch would need.
- **The gate reads the unweighted part-sum; ranking keeps A7 §3's weights.** A7 §4 says "the gate sees the per-part scores as well as the sum". R1 measured τ on one cue of prompt, previous turn and paths together, the unweighted sum's scale.
- **A fit is never trusted yet.** A7 §4 trusts one from 300 prompts only after the repo's annotated-cue recall check, and no repo has annotated cues. An earlier round trusted seeds plus acks and doubled τ.
- **The silence log names a prompt by `prompt_id`,** not by a hash of its text: the stored text drops a final period, so a hash never resolved.
- **Mean idf rides in the snapshot header at version 1.** A version bump cost 410 ms per Submit at 20k rows while the snapshot was rebuilt in process; an older snapshot is rebuilt at the next sleep instead.
- **A typed request is an episode only with the gate on.** With it on, a typed request needs MEDIUM from two parts (A4 §3.0: it states what the user asked, not what is true). Statements the user typed stay facts.
- **D26: a question asserts nothing,** so it restates only a question.
- **Shadow is `main`'s admission, not the gate's pre-processing** (5faa275b5, after the measurement). The echo filter and newest-per-subject rule run before the cut on the gate's path only.
