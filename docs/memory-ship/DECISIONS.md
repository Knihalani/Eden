# Eden Memory — Decision register

**Dated 2026-09-29.** Every open choice from the review rounds, decided. Each decision cites the evidence it rests on. Where a decision overrules a recommendation from one of the research reports, the row says so and says why.

**Precedence:**
- This register decides.
- `A4-DELIVERY-CONTRACT.md` specifies what the register decides.
- `ROADMAP.md` orders the work.
- Research reports (`research/R0–R6`) and appendices A1–A3 are evidence. Where they disagree with this register, the register wins.

**Evidence keys:**
- **R0** hook facts (raw docs)
- **R1** cue experiment (+ Addendum A, policy triggers)
- **R2** cue architecture
- **R3** review of the new docs (real transcripts, extractor runs)
- **R4** citation audit
- **R5** scope on 19 real repos
- **R6** real usage (this machine's transcripts)
- **A1** first adversarial review
- **A2** technical choices
- **A3** nature mechanisms

| # | Decision | Evidence |

| **D12** | **Authority by entry type, with pasted spans stripped.** `src=user` covers: <br>• `UserPromptSubmit.prompt`; <br>• transcript `type=user` lines that are not meta, not compact summaries, not tool results, and not `<command-`, `<local-command`, `<system-reminder>`, `<task-notification>`, `<agent-message>`, `<cross-session-message>`, `<teammate-message`, or `<bash-` wrappers; <br>• queued prompts. <br>Before extraction, remove: spans between `<pasted_content id=…>` and `</pasted_content id=…>` lines (exact, when the host marks pastes, R0 F30); fenced code; `>` quotes; runs of ≥ 3 lines without sentence punctuation; spans ≥ 200 chars that also occur in a recent tool result. Pasted spans become `src=paste` episodes, and they never create slot facts, policies or intents. Assistant text, compaction summaries and tool output create episodes only. Stripping runs **before any LLM** sees text (R8: unstripped, 3 of 4 models extracted from 8–16 of 26 pastes). Content-safety models are at most a second screen on `tool`/`paste` episodes: they caught 9–10 of 20 poison texts and 0 of 4 assistant-claimed authority cases (R8 E4) <br>**Partly built in P0.2:** the memory hook marks a transcript tool result (and a PostToolUse result) `src: "tool"`, and `observe` tags rows from it `src:tool` and rows from assistant text `src:agent`, so they keep their true source (A6 §2.1, "from a tool result" in D14's wording) and meet A7 §4's episode rule (D17). That they create episodes only, the wrappers, the paste stripping and `sanitizeForStore` are P0.4's <br>**Built in P0.4:** the hook reads each transcript entry by source (`authoredTexts` in `src/memory-authority.ts`: `user`, `paste`, `tool`, `agent`; host text such as meta lines, wrappers and non-human submits is not memory), splits the Submit prompt's pasted spans off as `paste` episodes, and reads Stop and SessionStart payload text as the agent's. ## R10 proposals (pending the user's decision; not adopted)

Raised by the R10 research programme (`research/R10-retrieval.md`; evidence in `research/R10/LEDGER.md`). Each is a proposal with measured grounds. None changes behaviour until the user accepts it and a slice ships it.

- **R10-1 · Push stays the core; an optional pull channel is a secondary extra (A4 §5).** Revised 2026-10-19 after the user's review: Eden's edge is surfacing what the agent does not know to ask.
  - *Evidence:* when the agent decides when to look (agent-pull), its proactive recall is only 0.22–0.23, and its trigger recall 0.19. A strong model with the whole store gets 0.46–0.52 and 0.50 (C2-E5, E8, C3-E1). The agent asks only about what it already suspects exists.
  - On explicit needs it is precise: 2–2.5× the hook's precision on the same events.
  - *Proposal:*
    - Eden keeps deciding, unasked, what the agent sees: proactive needs, triggers, rules on actions, corrections.
    - The hard thinking moves into sleep time (P8.8, and R10's anticipation and per-user need models), so the hook stays fast and model-free (D15).
    - Hosts that support tools may also get a memory index and a `recall` tool, for explicit "what was that again?" needs.
- **R10-2 · StreamBench is the primary retrieval benchmark.**
  - R1, R8 and LifeBench pairs are secondary arms. No slice may claim a retrieval gain on them alone.
  - *Evidence:* pair fixtures overstated lexical recall (0.47–0.56 on pairs vs 0.21 on streams at a realistic silence; C1-E2).
- **R10-3 · Bullet precision and silence are outcome metrics, not only token budgets.**
  - *Evidence:* re-measured with a clean protocol (C5-E1: one responder prompt per condition, a judge that sees the episodic history). On code no-need turns the hook vote's packet scored −0.467 against no memory (6 of 15 turns worse, 1 better), against an empty-packet noise floor of −0.067. On plan-need turns the right packet scored +1.23. A wrong packet costs about 40% of what a right one gains. (C4-E10's 0.0 came from a confounded protocol and is superseded.)
  - *Proposal:* every retrieval slice reports `stream-downstream`, and must not lower it on no-need turns.
- **R10-5 · Push with an off-hook check, and date every delivered memory.**
  - *Evidence (C5-E7, fresh turns):* the hook picks ≤ 15 candidates with no model; a small model checks them outside the hook; the packet arrives at the turn's first tool call; each row is prefixed "[as of <date>]". Per-turn effect on replies: code +0.113, life +0.125, against today's plugin 0.0 and −0.004. Where memory is needed: +0.56 and +0.6; where not: +0.07 and 0.0. 95% CIs of the difference include 0 (n ≈ 70 per world), so this is a strong lead, not yet a firm result.
  - *Why dates matter (C5-E6):* without dates a wrong packet costs about −0.6 on a no-need turn; with dates about −0.1.
  - *Proposal:* the push path keeps the hook model-free and adds (a) an off-hook verifier with a calibrated threshold and (b) dated rows in every packet. Eden still decides, unasked. Needs: latency and cost measurement, and a firmer sample, before a slice is pre-registered.
  - *Also (C5-E5):* any batched sleep compiler needs a cross-batch supersession pass; its `supersede` op could only reach rows of the same batch.
- **R10-4 · Sleep-time models may write retrieval cues and situations, not only extract facts** (D34, §6a).
  - *Evidence:* compiled `when` cues and self-play situations raised silence by +0.16–0.26 at equal recall on both worlds (C1-E6, C2-E7).
  - This needs an offline model for the sleep step (NIM today). The model must differ from any model that writes evaluation data.
