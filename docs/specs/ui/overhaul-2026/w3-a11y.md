## 2. Known failures / risks (Wave 1 evidence)

### 2.1 Touch targets &lt;44px

| Control | Size | Cite | Priority |
|---|---|---|---|
| `Button` `sm` | h-8 = **32px** | `button.tsx:31`; mobile-shell §5 | **P0** on mobile-critical / primary actions |
| `Button` default / icon | h-10 = **40px** | `button.tsx:30,33` | **P0** raise primary size to **min-h-11** (44) |
| Improve Approve/Reject | **h-7 = 28px** | `improve/page.tsx:505-526` | **P0** |
| Labeling board `size="sm"` | 32px | `labeling/queues/[id]/page.tsx` | **P0** |
| DataTable checkbox | h-4 w-4 | `data-table.tsx` | **P1** (extend hit area / padding) |
| Sidebar `NavItem` / `NavSubItem` | py-1–2, no min-h | `portal-chrome.tsx` | **P1** |
| Dense hub toolbars | h-5 / h-6 | consolidated §9 | **P1** |

**Already compliant:** `MobileBottomNav` core + More rows `min-h/w-[44px]`; hamburger/close; some empty-state CTAs `min-h-11`; Switch (mobile); W10.1 locks on Issues/Traces hub tabs `min-h-11`.

### 2.2 Suspense blanks (`fallback={null}`)

| Location | Risk | Cite |
|---|---|---|
| Settings page | Blank flash before tabs | states-loading Pattern A |
| Gateway redirect / Agents connect | Same `useSearchParams` + null | `:45-53`, `:130-139` |
| Replay, SelectedTrace, chrome overlay | Transient blank Status | states-loading §B |

**Req:** Replace with skeleton / `Loader2` + `role="status"` `aria-live="polite"` / `aria-busy`. Ban new `fallback={null}` (lint in Wave 6).

### 2.3 Nested interactive — TranscriptView (AUDIT H2)

| Fact | Detail |
|---|---|
| Audit status | **H2 still open** ([`w1-specs-gap.md`](./w1-specs-gap.md)) |
| Code note | Sibling expand + row-select buttons to avoid `<button>`-in-`<button>` (comment cites H2) |
| Residual risk | Dense tool one-liners, subagent cards, copy/toggle controls inside selectable rows; overlapping hit targets; screen-reader name collisions |
| Density | Top P0 micro-type file (score 84: `text-[10px]`×21, `text-[9px]`×2) |

**Req:** Structural a11y pass — one primary activation per row; secondary actions as siblings with ≥24px targets and distinct accessible names; axe + keyboard re-audit on `/traces?traceId=`.

### 2.4 Focus visibility / focus obscured

- Skip link + `--focus-ring` exist; `FOCUS_RING_VARS` unused; `FOCUS_RING_CLASS` rare ([`w1-component-inventory.md`](./w1-component-inventory.md)).
- Sticky `h-11` header + fixed bottom nav → **2.4.11** when focused control scrolls under chrome ([`w2-web-ux-standards.md`](./w2-web-ux-standards.md) S4).
- Sticky filters (Wave 3 layout rule) must add scroll-padding, not worsen obscuring.

### 2.5 Contrast / micro-type

Fake density via 9–10px type fails **1.4.3** readability and is not a density system ([`w2-web-ux-standards.md`](./w2-web-ux-standards.md) S7 anti-pattern). Hotspots: TranscriptView, ApprovalCard, alerts, guardrails, fleet, portal-chrome.

**Floor:** Compact density may shrink row height by 4/8px; must **not** set readable UI below `text-xs` (12px) or shrink touch chrome.

### 2.6 Hub tablists

Zero hubs import `ui/tabs`; all hand-roll `role="tablist"` ([`w1-hub-surfaces.md`](./w1-hub-surfaces.md), gap-matrix §2.12). Issues/Traces already locked to `min-h-11` in Vitest — keep that floor when migrating to Radix Tabs.

## 3. Button / CTA requirements

### 3.1 Size floor

| Role | Min size | Notes |
|---|---|---|
| **Primary CTA** (page actions, empty-state, Improve Approve/Reject, mobile chrome) | **`min-h-11`** (44px) + adequate width (≥44 or padding that yields 44×44) | Prefer `Button` size that meets this; do not use `sm` on these |
| **Secondary / dense table row actions** (desktop Compact only) | ≥**24×24** (2.5.8) | Prefer 32px+; never &lt;24 |
| **Icon-only** | **min-h-11 min-w-11** on touch / sticky chrome; ≥24 elsewhere | Match MobileBottomNav pattern |
| **Forbidden** | Improve/Labeling primary actions at `h-7` / `size="sm"` on `&lt;lg` | Empty-state already uses `min-h-11` — board must match |

### 3.2 Focus / hover

| State | Requirement |
|---|---|
| **`:focus-visible`** | Visible ring using `--focus-ring` + offset (global or `FOCUS_RING_CLASS`). Never `outline-none` without replacement ring. |
| **Hover** | Distinct from focus; use `hover:bg-[var(--accent-bg)]` / variant tokens — no color-only status. |
| **Disabled** | `aria-disabled` or native `disabled`; contrast may drop but remain distinguishable. |
| **Primitive** | All accent CTAs through `@/components/ui/button` — kill raw accent `<button>` fragments (~53 cite in inventory). |

### 3.3 Anti-drift

- New hub/page CTAs: `Button` only.  
- Lint (Wave 6): flag `h-7` / `size="sm"` on Improve board + MobileBottomNav siblings.

## 4. Keyboard contracts

### 4.1 Traces / master–detail (`DetailPanelShell`)

| Key | Behavior | Status |
|---|---|---|
| **`j`** | Next row / next block (`onNext`) | Implemented when callback passed; skip if focus in INPUT/TEXTAREA/contenteditable |
| **`k`** | Previous (`onPrev`) | Same |
| **`Esc`** | Close panel; clear `traceId` / `spanId` (URL contract) | Implemented `onClose` |
| **`f`** | Fullscreen detail | Contract in Laminar docs — wire if product exposes fullscreen |
| **`⌘F` / `Ctrl+F`** | In-trace search when wired | P1 when SpanSearchBar owns focus |

Align with [`w2-laminar-contracts.md`](./w2-laminar-contracts.md) B.3 / U01. Row must expose `aria-selected` when focused.

### 4.2 Transcript

| Key | Behavior |
|---|---|

| `k` / `ArrowUp` | Previous |
| Expand/collapse | Own control; not nested inside row-select button |

| Req | Detail |
|---|---|

- Labeling: hotkeys exist; must also offer **visible** ≥44px controls (2.5.7 / keyboard+pointer parity).
