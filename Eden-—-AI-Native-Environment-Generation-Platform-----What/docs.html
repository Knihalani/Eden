Overview

Eden is a REST API for generating complete, runnable AI agent environments from natural language descriptions. Submit a job, stream real-time pipeline events via SSE, and fetch the generated code when the pipeline completes.

›
All endpoints return JSON. Authenticate with a session cookie (web app) or an Authorization: Bearer <token> header using an API key from your account settings.
Base URL
api.edenai.dev/v1
Auth
Session or Bearer
Format
JSON
Versioning
URL path prefix

Authentication

The Eden API supports two authentication methods. Session cookies are used by the web application. Programmatic access requires an API key.

COOKIE
Session cookie
Web app — automatic after login. Sent automatically by the browser.
HEADER
API key — Authorization header
Programmatic access. Generate keys in Settings → API Keys.
Authorization: Bearer eden_production_kQ9xZ2mP3rL8...

Submit Job — POST /jobs

POST /v1/jobs Submit a new environment generation job
Request body
FieldTypeDescription
descriptionstring requiredNatural language description of the agent environment to generate.
tagsstring[]Optional tags to label and filter this job.
difficultyenumOne of easy, medium, hard. Default: medium.
metadataobjectArbitrary key-value pairs attached to the job and returned in trace events.
Example request
curl -X POST https://api.edenai.dev/v1/jobs \ -H "Authorization: Bearer eden_production_kQ9xZ2..." \ -H "Content-Type: application/json" \ -d '{ "description": "Customer support bot with multi-turn dialog, Slack integration", "tags": ["slack", "websockets"], "difficulty": "medium" }'
import httpx client = httpx.Client( base_url="https://api.edenai.dev/v1", headers={"Authorization": "Bearer eden_production_kQ9xZ2..."} ) resp = client.post("/jobs", json={ "description": "Customer support bot with multi-turn dialog", "tags": ["slack", "websockets"], "difficulty": "medium" }) job = resp.json() # → {"job_id": "j_bd3f81", "status": "pending", ...}
const resp = await fetch('https://api.edenai.dev/v1/jobs', { method: 'POST', headers: { 'Authorization': 'Bearer eden_production_kQ9xZ2...', 'Content-Type': 'application/json' }, body: JSON.stringify({ description: 'Customer support bot with multi-turn dialog', tags: ['slack', 'websockets'], difficulty: 'medium' }) }); const job = await resp.json(); // → { job_id: 'j_bd3f81', status: 'pending', ... }
Response — 201 Created
{"job_id": "j_bd3f81", "status": "pending", "created_at": "2026-05-28T10:04:12Z"}

List Jobs — GET /jobs

GET /v1/jobs List all jobs with optional filters, search, and pagination
Query parameters
ParamTypeDescription
statusenumFilter by: pending, running, completed, failed
qstringSearch by job_id or description text
sortenumnewest (default) or oldest
limitintegerResults per page. Default: 20. Max: 100.
offsetintegerPagination offset. Default: 0.
curl "https://api.edenai.dev/v1/jobs?status=running&limit=10" \ -H "Authorization: Bearer eden_production_kQ9xZ2..."
resp = client.get("/jobs", params={"status": "running", "limit": 10}) jobs = resp.json()["items"]
const params = new URLSearchParams({ status: 'running', limit: 10 }); const resp = await fetch(`https://api.edenai.dev/v1/jobs?${params}`, { headers: { 'Authorization': 'Bearer eden_production_kQ9xZ2...' } }); const { items: jobs } = await resp.json();

Stream — GET /jobs/{job_id}/stream

GET /v1/jobs/{job_id}/stream SSE stream — real-time pipeline events, stage changes, and output fragments
›
This endpoint returns a Server-Sent Events stream. Each event carries a type field (status, stage, message, done) and a data payload.
import httpx from sseclient import SSEClient with httpx.stream("GET", "https://api.edenai.dev/v1/jobs/j_bd3f81/stream", headers={"Authorization": "Bearer eden_production_kQ9xZ2..."}) as r: for event in SSEClient(r): print(event.data) # {"type":"stage","data":"fact_check"}
const es = new EventSource( 'https://api.edenai.dev/v1/jobs/j_bd3f81/stream', { headers: { 'Authorization': 'Bearer eden_production_kQ9xZ2...' } } ); es.addEventListener('stage', (e) => { console.log('Stage:', e.data); }); es.addEventListener('done', (e) => { console.log('Completed:', JSON.parse(e.data)); });

Error Codes

StatusMeaningUsual resolution
400Bad request — invalid fields or missing required parameters.Check request body against schema.
401Unauthorized — missing or invalid authentication token.Provide a valid session cookie or API key Bearer token.
403Forbidden — valid auth but insufficient permissions.Request elevated access from an org owner.
404Not found — job_id or resource does not exist.Verify the job_id is correct and belongs to your account.
409Conflict — job is not in a cancellable state.Only pending or running jobs can be cancelled.
429Too many requests — rate limit exceeded for this plan.Back off and retry. Check Retry-After header.
500Internal server error — something went wrong on Eden's side.Check status.edenai.dev and retry with exponential backoff.
