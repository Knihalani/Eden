# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

In short: be kind, be respectful, assume good faith. Harassment, personal
attacks, and publishing others' private information are not acceptable, in
issues, pull requests, or any other project space.

To report unacceptable behaviour, contact the maintainer
([@Knihalani](https://github.com/Knihalani)) through GitHub. Reports are
handled confidentially.

The full text of the Contributor Covenant is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
