Security

Eden is in soft launch. Observability data is sensitive — this page states what we do today and how to reach us for security questions. We do not claim third-party certifications on marketing surfaces.

What we do today

Encryption in transit

Client traffic to Eden uses HTTPS (TLS). We do not publish cipher-suite or mTLS details beyond what your browser or SDK negotiates with our edge.

Authentication

Portal sign-in is handled by Clerk (sessions, MFA available). API access uses org-scoped API keys you rotate from Settings.

Org RBAC & audit

Per-org roles gate workspace and settings access. Sensitive actions are recorded in the audit log where that surface is implemented.

PII at ingest

Payloads can be masked at ingest using your redaction rules. You control what raw content is retained.

Tenant isolation

Customer data is scoped by organization. Cross-org access is denied at the API layer.

Report a vulnerability

Found a security issue? Email security@eden.dev. We acknowledge good-faith reports and will follow up with triage steps. Please do not file public GitHub issues for suspected vulnerabilities.

Enterprise security questionnaires and formal audit artifacts are not available during soft launch — contact us to discuss your requirements.
