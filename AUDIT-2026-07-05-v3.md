## 2. What changed since v1.7 (pass 2)

### 2.1 New: `SymbolGraph` (replaces Greptile as default)

**File:** `src/eden/code_change/graph/symbol_graph.py` (~1066 LoC)

The user told us Greptile was an *example* in the brief, not a real
decision. We built a real in-process code-symbol index:

* **Python files** parsed with `ast` — extracts functions, classes,
  methods, decorators, call sites, attribute access, imports, and
  top-level assignments (constants). Parent-class tracking is
  handled via an `ast.walk` parent map.
* **TS / JS / Go / Java / Rust / Ruby** files parsed with lightweight
  regex scanners for `function`, `class`, `const`/`let`/`var`, and
  method declarations. Upgradable to tree-sitter later without
  touching the protocol.
* **SQLite persistence** at `$EDEN_SYMBOL_GRAPH_DB` (default
  `./.eden/symbol_graph.sqlite`) with WAL mode. Re-indexing after
  a rebase is cheap — `git diff --name-only` tells us which files
  changed.
* **Bulletproof** — every method degrades to `None` / `[]` on any
  failure. Missing / unreadable files are silently skipped.

**Bug fixed during implementation:** `references` is a reserved
keyword in SQLite; the original schema silently failed to create
the table. Renamed to `ref_index`.

### 2.2 New: `LocalCodingAgent` (replaces OpenHands cloud as default)

**File:** `src/eden/code_change/agent/local_coder.py` (~660 LoC)

The user told us OpenHands is open source — install it locally.
We shipped a three-layer agent:

* **`OpenHandsLocalAgent`** — shells out to the OpenHands Python
  SDK / CLI via `subprocess.run` with a hard timeout (default 60s).
  Probes `which openhands` / `import openhands` once and caches
  the result for 60s so we don't re-probe every call.
* **`ScriptedCodingAgent`** — stdlib-only deterministic patch
  generator. The catalog of safe operations:
  * `add_import` — adds a missing top-level import
  * `add_docstring` — adds a TODO docstring to the first function/class
  * `add_log_line` — adds `import logging` + `logger.debug(...)`
  * `annotate_unhandled` — annotates a bare `except:` clause
* **Combined dispatcher** — tries OpenHands-local first, then
  scripted, then a structured `report_only` payload. Catches
  every exception at the dispatch layer. **Never returns `None`.**

| Factory | Old default | New default |

## 3. Bulletproof guarantees

* `LocalCodingAgent.run(...)` always returns a `PRResult`. Never `None`. Never raises.
* `ScriptedCodingAgent.run(...)` always returns a `PRResult`. Never `None`.
* `SymbolGraph.{status,request_index,query,find_affected_areas}` never raises. Returns `None` / `[]` on any failure.
* `OpenHandsLocalAgent` failures (timeout, non-zero exit, missing binary) become structured `report_only` payloads, not exceptions.
* `incident_trigger.run` keeps its existing `try/except` around the agent call as belt-and-suspenders — defensive in depth.

## 4. Cost analysis

| Path | Cost per call |
|---|---|
| SymbolGraph (every PR candidate) | $0 |
| LocalCodingAgent + scripted | $0 |
| LocalCodingAgent + OpenHands-local | Your marginal LLM cost (you point OpenHands at your model) |
| OpenHands Cloud (opt-in) | Paid (per OpenHands pricing) |
| EdenPatchAgent (opt-in) | LLM API cost (tracked per-call + per-day) |

The default path costs $0. Operators opt in to LLM-backed agents
explicitly via env vars.

## 6. Risks & follow-ups

1. **Regex scanners for non-Python are weaker than tree-sitter.**
   Acceptable for v1.7.1; we should add `tree-sitter` to
   `pyproject.toml` when the team has bandwidth. The scanners are
   isolated in `_parse_text_symbols` — upgrade is a single-file
   change.

2. **`OpenHandsLocalAgent` shell-out assumes `openhands --json --non-interactive`.**
   Different OpenHands versions accept different flags. We fall back
   to a plain invocation if the JSON flag is rejected. The actual
   CLI surface will need a small integration test once OpenHands is
   installed on the host.

3. **No retry on transient git failures.** The `_git_head_sha` /
   `_git_changed_paths` helpers fail-open. Acceptable — a stale
   index is harmless (the next call refreshes it).

4. **`SymbolGraph` `iter_files` caps at 20k files + 1 MiB per file.**
   Override via `EDEN_SYMBOL_GRAPH_MAX_FILES` /
   `EDEN_SYMBOL_GRAPH_MAX_FILE_BYTES`. For Eden's monorepo (1.5k
   files) the defaults are comfortable.

5. **`references` was a reserved word in SQLite.** Renamed to
   `ref_index` everywhere. No DB migration needed — this is the
   first version that uses the table.
