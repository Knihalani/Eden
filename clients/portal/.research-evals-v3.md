## API capability map (E0.7) — reuse only

Source of truth: `clients/portal/src/lib/api/resources.ts` (+ re-exports in `agents.ts` / `misc.ts` / `improve.ts`).

### What already returns enough for V3 UX

| Capability | API | Returns / behavior | UI compose (no new endpoint) |
|------------|-----|--------------------|------------------------------|
| Promote trace → dataset | `datasetsApi.promoteFromTrace` | `{ dataset_id, row_id }` per call | **Batch = sequential/parallel N calls** from selected trace IDs |
| Dataset CRUD / rows / import / snapshot | `datasetsApi.*` | Full spreadsheet ops | Start-experiment CTA → `offlineExperimentsApi.create` |
| fromSpan | `playgroundApi.fromSpan` | Persisted playground | Prefill + “From production” chip from query |
| Run / promote | `playgroundApi.runPersisted` · `promoteExperiment` | Run matrix blob · experiment record | Fail-first matrix UI; land on `/evals?tab=experiments&experimentId=` |
| Offline list / run / compare | `offlineExperimentsApi.list` · `run` · `compare` | `summary` grades map; `datapoints[]` with `grade`, `score_delta`, control/treatment I/O; optional `baseline_id` query | Baseline picker, Δ colors, grade chips, layouts |
| Char diff | `charDiff` (client) | Token spans | Diff mode panel |
| Labeling → dataset | `labelingQueuesApi.pushToDataset` | Push | Advanced leaf polish |
| Scores | `evalApi.listVersions` · `failureClusters` · `tagVersion` | Versions + clusters | Quiet Advanced panel |
| Studio / Synthetic | `metricStudioApi.*` · `qaApi.*` | Templates/metrics · QA runs | Advanced only |

### Gaps — UI-only vs true API holes

| Need | Status | Guidance for E1–E4 |
|------|--------|--------------------|
| Comparison grades Improve/Regress/Tradeoff/Tie | **Compose** from `datapoint.grade` / `score_delta` / summary keys | Do not invent `/compare/grades` |
| Summary \| List \| Grid | **UI-only** | Client layout over same compare payload |
| Persistent project baseline | **Gap (soft)** | Prefer URL/`useResourceUrlState` + local preference; no new BE in this fleet unless blocked |
| Batch promote-from-trace | **Compose** | Loop `promoteFromTrace`; no bulk endpoint required |
| Multi-prompt assertion matrix (Promptfoo YAML fidelity) | **Soft gap** | Use `runPersisted` matrix tasks as cells; do not invent scorer runtime |
| `experimentsApi` (intelligence traffic-split) | Unused in portal | **Out of Evaluate V3** — ignore |
| `playgroundApi.run` / `compare` (legacy prompt store) | Unused on playgrounds page | Prefer persisted playground path |
| `datasetsApi.generateColumn` / `exportUrl` / `listRows` | Underused | Wire if needed in E2; already exist |
| `evalApi` HIL / pairwise / CLHF / multimodal | Unused on Scores page | Optional E5; not MUST |

**Rule:** If a field is already on the compare/promote/fromSpan response, compose in UI. **Do not invent endpoints** in this fleet.
