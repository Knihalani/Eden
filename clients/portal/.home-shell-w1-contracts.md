## Locked contracts (freeze text)

### Ask AI — 1A
- Three doors → **one** surface: header utility icon · redesigned FAB · ⌘K/⌘J.
- Rail / overlay **collapsed by default**; never dual always-on rails.
- Header utility strip (L→R): **Search · Ask AI · Notifications** (user in sidebar).
- Coach: optional one-time tip after restore (W3) — not sticky noise; not permanently banned.

### Cookies — 2A
- Banner until Accept / Decline.
- After choice: render **null** — no fixed preferences pill.
- Reopen: Settings · Privacy · footer only.
- `--cookie-banner-offset` = `0` when hidden.

### Chrome bands + sinks
- ≤2 chrome bands above content (header + page toolbar).
- Always-on sinks ≤6: `sidebar` · `header` · `command-palette` · `banner` · `toast` · `ask-ai-fab`.
- Cookie is **not** a post-choice sink.

### Button / breadcrumb
- Icon-only shell controls = kit `Button size="icon"` only.
- Ban raw chrome `<button>` except a11y menu triggers when kit has no equivalent.
- Prefer kit `ui/breadcrumb.tsx` (extend in W5 for home root + ellipsis + category prefix).
