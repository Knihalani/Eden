When judge scores drift, Eden clusters failing traces, drafts a patch, and runs your evals. Suggestions land in an inbox — a human opens the PR. Eden never opens a PR on its own.

  • PR-suggestion inbox — trace-driven drafts; you open the PR
  • Deterministic + LLM-as-judge evals, regression alerts, golden-dataset replays
  • Cost budgets, PII redaction, RBAC, audit log

Questions before the first trace.

Eden is an observability and improvement platform for AI agents and LLM apps. Capture every call through an OpenAI-compatible gateway or drop-in SDK, analyse traces and evals in a multi-tenant workspace, and review human-gated patch suggestions when scores drift.

Use the gateway when you can set one base_url on an OpenAI-compatible client — no package install required. Use the SDK (eden-sdk / @eden-ai/sdk) when you want native instrumentation for Python or TypeScript frameworks. Both write the same traces; pick one path to first capture.

Soft launch is free — no credit card. Caps are $1/mo LLM spend on a personal workspace (1 seat) and $3/mo on an org workspace (up to 3 seats). Paid Team / Pro plans are not available yet.

PII is masked at ingest using your redaction rules. You can opt out of raw payload retention entirely; structured metadata is enough to run the product.
