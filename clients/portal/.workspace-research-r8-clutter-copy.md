# Wave 0 / R8 — Workspace clutter & copy debt

**Agent:** Research R8 · **Mode:** research-only · **Date:** 2026-07-21  
**Scope:** Authenticated portal Workspace IA + Settings / Audit / orgless chrome — `clients/portal` only.  
**Out of scope:** Product code changes; Observe / Evaluate / Improve leaf hubs except where they leak org/workspace copy; marketing site.  
**Authority:** Ambition A + Ghosts A (see `.workspace-research-r10-checklist.md`); DESIGN.md §4 Primary CTA; sibling R3 (Linear/Vercel/Stripe grammar), R9 (DESIGN addendum), R10 (MUST/SHOULD/NICE).

**No product code changes.**

---

## 1. Thesis

Workspace productization is blocked less by missing features than by **five copy/IA collisions**:

1. **Org vs workspace** — user chrome says both; empty states teach “workspace” then CTA “organization.”
2. **Dual audit** — `/audit-trail` and Settings `?tab=audit-log` are live, cross-linked, and ⌘K-promoted as two compliance homes.
3. **Mobile Workspace mismatch** — More sheet group labeled Workspace lists Improve/ops leaves, not desktop’s Audit / Settings / keys.
4. **Hand-rolled CTAs** — kit `Button` exists; Workspace leaves and orgless chrome still ship raw `<button>` / accent fills.
5. **Clutter** — Settings hub ~647 LOC, dual `*-tab` / `*-settings` pairs, ≥19 tab ids, Compliance + Advanced long-tail on first Settings paint paths.

Waves **2–9** should burn this as **prioritized copy + surface debt** (wording first where cheap; unify/redirect where Ambition A already locked). Do not invent Roles/SSO product (Ghosts A).

## 2. Org vs workspace wording

### Canonical target (Ambition A / R10 M13 · S5 · S21)

| Layer | Preferred user word | Keep “org” when… |
|-------|---------------------|------------------|
| IA group, breadcrumbs, empty titles, banners | **Workspace** | — |

| Personal mode | **Personal workspace** | Never “personal organization” in UI |
| Team mode | **Team workspace** | “organization” only when quoting Clerk / legal |

| `Create an organization` / `No organization yet` | Orgless + org leaf | `no-org-state.tsx` body + primary **“Create organization”**; `org-tab.tsx` / `org-settings.tsx` titles; dashboard / traces empty copy |

### Copy rules for Waves 2–9 (apply consistently)

1. **Empty / NoOrg / timeout:** title + body lead with **workspace**; CTA **Create workspace** (href may remain `/settings?tab=org`).
2. **Select scope:** **Select a workspace…** (not organization) on every Settings leaf + hub NoOrgState override.
3. **Admin contact:** **workspace admin** (not organization admin).
4. **Tab / menu / ⌘K labels:** rename user-visible **Organization → Workspace** (keep `tab=org` id until a deliberate redirect map).
5. **Do not** rename Clerk `OrganizationSwitcher` props or API paths in copy passes — only user-visible strings.
6. **Personal vs team:** one pair of phrases only — “personal workspace” / “team workspace”; kill “team organization” in SCIM notice (`settings/page.tsx`).

## 3. Dual audit (compliance split)

### What exists today

| Surface | URL | File | Role (data) | IA entry |
|---------|-----|------|-------------|----------|
| **Audit trail** | `/audit-trail` | `src/app/(portal)/audit-trail/page.tsx` (~401 LOC) | Chain-verified **agent** events + compliance pack export | Sidebar **Workspace → Audit trail** |
| **Audit Log** | `/settings?tab=audit-log` | `settings/_components/audit-log-tab.tsx` (~282 LOC) | Org **admin action** history (member.invited, settings.updated, …) | Settings Compliance tab (not `defaultVisible`); ⌘K **Settings · Audit Log** |

They are **not the same API**, but they are **two compliance homes** in product language and navigation.

### Collision evidence

- Audit trail header **More → “Settings audit”** → `/settings?tab=audit-log` (explicit dual path).
- ⌘K promotes Settings Audit Log; sidebar only lists Audit trail.
- Retention / exports copy still say **“Audit logs”** / “Org audit-log rows” while IA says **Audit trail**.
- R10 **M3 / M15**: canonical URL **`/audit-trail` only**; `?tab=audit-log` **redirects**; fold former audit-log as segments (e.g. Events \| Chain packs).

### Wave mapping

| Wave | Copy / IA debt | Exit smell if skipped |
|------|----------------|------------------------|
| **1** (contract) | Redirect stub + stop advertising dual in new chrome | Bookmarks break later |
| **6** | Unify UI; rewrite EmptyState to teach **one** Audit trail; toolbar ≤5; retire cross-link “Settings audit” | Users still hunt “which audit?” |
| **9** | ⌘K / deep-link hygiene; dual FS stubs redirect-only | ⌘K reopens dual |
| **2 / 11** | Wording: Audit **trail** everywhere user-facing; “audit log” only as API/export type name if needed | Residual S21 |

**Copy bank (post-unify):**

- Title: **Audit trail**
- Subtitle: **Workspace activity and chain-verified agent events** (segment-specific lines under tabs)
- Empty: **No audit events yet** — teach filters / permissions, not a second Settings destination
- Orgless: **Select a workspace to view the audit trail** (drop “organization”)

## 4. Mobile Workspace mismatch

### Desktop (source of truth)

`src/lib/sidebar-config.ts` — group **Workspace**:

- Audit trail → `/audit-trail`
- Settings → `/settings` (+ child API keys, advanced Webhook DLQ)
- Quickstart (docs)

### Mobile (broken label)

`src/components/portal-os/MobileBottomNav.tsx` — More sheet group **`id: "workspace"`, label: "Workspace"**:

| Link | Desktop group |
|------|----------------|
| Artifacts | Improve / ops (not Workspace) |
| Alerts | Observe-adjacent |
| Ledger / Promotions | Improve |
| Debug sessions | Advanced Observe |

Settings lives under More → **Account**, not Workspace. **Audit trail is absent** from More.

### Debt

- Same word **Workspace** means different IA on phone vs desktop → R10 **M4** fail.
- Orgless / first-run teaching “open Workspace” misroutes mobile users to Artifacts/Alerts.

### Target mobile Workspace group

**Audit trail · Settings · API keys** (parity with desktop scent). Move Artifacts / Alerts / Ledger / Promotions / Debug under Improve or a neutral **More / Tools** group — not under Workspace.

Wave ownership: **Wave 1** (IA contract) + freeze assert Wave **12**; copy labels only need a one-line More sheet rename when links move.

## 5. Hand-rolled CTAs

### Contract

R10 **M7**: Workspace = 0 new hand-rolled accent CTAs; migrate existing; Wave **9** ratchet via `lint:portal-classes` (`ACCENT_CTA` baseline **2**).

### CTA copy rules (with kit migration)

1. One solid primary per leaf (**Create workspace**, **Invite**, **Create key**, **Save**, **Upgrade**).
2. Secondary = `Button variant="outline|ghost"` — no second solid brand.
3. Destructive = `variant="destructive"` or DangerZone only — kill parallel `border-error` raw buttons in `org-tab`.
4. Orgless: **Create workspace** primary; **Open Workspace settings** secondary link text (not “Organization settings”).

## 6. Clutter (Workspace-scoped)

### Structural

| Offender | Evidence | Why it clutters copy |
|----------|----------|----------------------|
| Settings hub size | `settings/page.tsx` **~647 LOC** | Tab registry + ghosts + notices + bodies in one file → inconsistent empty strings |
| Tab strip | **19** `TABS` ids; **6** `defaultVisible` + Audit Log + large Advanced | Users see Compliance/Advanced language before overview exists |
| Dual audit | §3 | Two names for “compliance” |
| Dual FS modules | `org-tab`↔`org-settings`, `members-*`, `api-keys-*` | Drift: “No organization yet” vs tour-aware workspace sentences |
| Mobile mislabel | §4 | Workspace means ops leaves |
| Triple location (global) | Breadcrumb category · PageHeader · help | Worsens Settings (“Workspace · Settings · Organization”) |
| Micro chrome | `text-[10px]` / half-step spacing in Advanced tabs | Competes with body copy; class lint ratchet |

### Anti-clutter copy moves (cheap)

- Kill redundant “No organization yet. Create an organization…” double openers (`org-tab`).
- One orgless paragraph template (shared helper string) reused by dashboard / traces / NoOrgState / members.
- Overview (Wave **2**): identity + plan + members count + key health + audit snapshot — **no** second product home prose.
- Advanced: collapse; no SCIM/Roles/SSO marketing sentences (Ghosts A).
