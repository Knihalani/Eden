## State matrix (verifier: first-run ≠ empty ≠ error)

| State | When | Root / region marker | Primary UI | Must not look like |
|-------|------|----------------------|------------|--------------------|
| **Loading** | Org sync / route pending | `data-home-shell-state="loading"` | `HomeDashboardSkeleton` (KPI strip + diagnosis + failures) | Empty inbox / error |
| **NoOrg** | Signed in, no workspace | `data-home-shell-state="no-org"` · `data-query-state="empty"` | `NoOrgState` create/sync CTA | First-run waiting / telemetry error |
| **First-run** | Org linked, zero traces, traces query not in error | `data-home-shell-state="first-run"` · `data-home-shell-listening` | `HomeFirstRun` — listening pulse + **one** doctor next step | Period-empty failures / ErrorState |
| **Error** | Telemetry shard failure | `data-query-state="error"` · `data-home-shell-state="error"` | `ErrorState` + Retry (page banner) or failures unavailable slot | Calm empty / first-run listening |
| **Ready** | Has traffic (not first-run) | `data-home-shell-state="ready"` · `data-query-state="ready"` | KPI → Diagnosis → Failures → quiet links | — |
| **Empty (period)** | Ready + no failures in window | nested `data-home-shell-state="empty"` · `data-empty-kind=period-empty\|zero-data` | `RecentFailuresCard` EmptyState | `Waiting for first event` / FIRST_EVENT_WAIT |

**Mutual exclusion (code):** `isFirstRun` requires `!tracesQuery.isError` and no traffic → first-run branch never mounts `HomeKpiStrip` / period-empty card. Error banner can coexist with first-run only for *non-traces* shard failures (summary/cost); traces error exits first-run.
