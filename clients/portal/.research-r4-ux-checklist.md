## MUST (ship / gate overhaul)

| # | Practice | Why (citation) | Eden surfaces |
|---|----------|----------------|---------------|
| M1 | **Progressive disclosure: primary ≤ few frequent actions; advanced on request** with clear “Advanced / More / Overflow” | NN-PD: show core first; secondary only on demand; improves learnability, efficiency, errors | **Chrome** toolbar; **Traces** ≤5 primary actions; **Settings** ≤8 visible tabs; **Improve** plan wizards; span Tree/Timeline as power modes |
| M2 | **Strong information scent on every nav / progression control** — descriptive labels, not vague verbs (“Explore”, “Engage”) | NN-IS + NN-PD: scent = label + context; weak scent → wrong path or abandon | **Sidebar** labels; **PageHeader** titles; **⌘K** command names; **Traces** view tabs (traces/spans/sessions); kill dual Observe IA scent collision |
| M3 | **Empty ≠ blank; distinguish first-run / filtered-empty / error / loading** | NN-ES: status + learnability + direct path; never show “No records” while still loading | **Home** first-run; **Traces / Issues / Alerts / Evals / Datasets** empty; filter-empty with Clear filters CTA |
| M4 | **Empty states include one primary next action** (link/button into workflow) | NN-ES guideline 3 | First-event waiting → install SDK; Alerts → Create rule; Improve → Start plan |
| M5 | **Optimize value density, not pixel cram** — value ÷ (time × space); prefer faster decisions over more widgets | STROM: visual ≠ information ≠ temporal ≠ value density | **Home** health strip (not portal-of-everything); **Traces** transcript-first; Compact density toggle for tables |
| M6 | **Tables are first-class product, not edge cases** — invest in pagination, badges, filters, combo boxes as system primitives | HC: dense tables are the product; building blocks reduce overload | **Traces** list; **Issues**; **Ledger**; **Agents**; **Experiments** |
| M7 | **Semantic color for system state only; never hue-as-quantity** | HC + NN-DB: color categorical/secondary; length/position for quantities; a11y | Status badges; span-kind pills in **trace transcript only**; KPI sparklines via length/position not rainbow |
| M8 | **Dashboard = glanceable operational answer, not exploratory portal** | NN-DB: min interaction/cognition; length & 2D position | **Home `/dashboard`**: diagnosis + next action + recent failures; deep explore → Traces/Improve |
| M9 | **Declutter chrome: remove non-decision ink; focus the critical pattern** | AJL: declutter+focus ↑ clarity, professionalism, pattern recall | ≤2 chrome bands; kill PageHelpHint triple; demote AI FAB; one ⌘K surface |
| M10 | **Accessible data tables: native `<table>` / headers / scope; `aria-sort` on sorted `th`; sort via header `<button>`** | WAI-ST, WAI-GT, AR-SORT | All hub tables + detail grids |
| M11 | **Announce dynamic sort / filter / live updates** (`aria-live="polite"`); don’t rely on visual arrows alone | AR-SORT: NVDA/VO often silent on sort | Traces sort; Issues triage; Live mode appends |
| M12 | **Loading ≠ empty** — skeletons/progress while fetching; empty message only after settle | NN-ES anti-pattern | Every hub `loading.tsx` + inline panels |
| M13 | **One primary CTA per screen; secondary ghost** | Stripe/Linear craft + DESIGN.md; reduces choice overload | All hubs; Settings save; Improve promote |
| M14 | **Design every state** (loading, empty, partial, stale, error, live) | HC: living system; users must see work happening | Trace detail; Home KPIs; Alerts; Online scoring |
| M15 | **Keyboard-complete primary triage paths**; focus visible; ≥ AA contrast on text/chrome | HC a11y-as-usability; WCAG | Chrome, Traces master–detail, Command palette |

## Anti-patterns to reject

1. Blank panels with no status (NN-ES).  
2. “No data” while request in flight (NN-ES).  
3. 18–22 first-paint toolbar controls (NN-PD / M1).  
4. Dual entry points for same job (`/observability` + `/traces`) — scent collision (NN-IS).  
5. Pie/donut/3D KPI chrome on Home (NN-DB).  
6. Sortable columns without `aria-sort` / live announcement (WAI / AR-SORT).  
7. Decorative card soup & dual side rails open (Stripe craft / plan D-rules).  
8. Equating whitespace removal with “density” (STROM: optimize value/time).
