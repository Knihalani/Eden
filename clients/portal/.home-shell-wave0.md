## 2. Laminar Ask-AI overlay interaction notes

**Primary evidence:** `lmnr-home-scroll1.png`, `lmnr-home-scroll2.png`; supporting: `lmnr-home-full.png`, `lmnr-docs-scroll0.png`, `OBSERVATIONS-R10.md`.

### FAB
- **No persistent FAB** on marketing, docs, pricing, or app sign-in (`lmnr-home-scroll0.png`, `lmnr-docs-*.png`, `lmnr-app-*.png`).
- Entry is **contextual**: pane **Chat** (spark + label), then overlay. Quiet until you’re in a run.

### Overlay vs push
- `lmnr-home-scroll2.png`: floating **“Chat with trace”** panel (~⅓–½ of mock width) on the **right**; dense dashboard remains visible underneath. **Overlays; does not reflow** the page.
- Companion state (`lmnr-home-scroll1.png`): Chat as pane-local tab with transcript still primary.

### Citation / evidence chips
- Inline chips: colored tool icon + **monospace** span/tool id (e.g. `ai.streamText.doStream`) — jump-to-context, not footnotes (`lmnr-home-scroll1.png`, `lmnr-home-scroll2.png`).
- Same chip grammar in Signals callout above transcript.

### Open / close
- Open: Chat tab · composer placeholder “Summarize, debug, and more.” · orange circular send.
- Close: Signals banner has clear ×; chat panel crop shows weaker header dismiss (layered UI).
- Docs: **Search… + ⌘K** only — no Ask FAB (`lmnr-docs-scroll0.png`). No ⌘J visible in corpus.

### Eden mapping for locked **1A**
| Steal | Adapt |
|-------|--------|
| Density-preserving overlay | Three doors → **same** overlay: header icon · redesigned FAB · ⌘K/⌘J |
| Citation chips (icon + mono id) | Eden evidence language, not Laminar orange/purple brand |
| Quiet contextual open | Header spark/icon as primary discoverability |
| Redesigned FAB: smaller, labeled-or-stronger icon + tooltip | Not a loud marketing bubble; not Laminar brand |

**Verdict:** Laminar proves Ask AI can be discoverable **without** an always-on marketing FAB — Eden 1A adds header + FAB for discoverability, but the **interaction target** is Laminar’s overlay-on-density, not a second always-open rail.

## 8. Critic — must-steal vs anti-clone

### Must-steal (ship these ideas)

1. **Ask AI as density-preserving overlay** (Laminar `lmnr-home-scroll2.png`) — three doors, one surface.  
2. **Citation / evidence chips** into traces (Laminar).  
3. **Slim single header ~40–56px** + breadcrumb-first location (Braintrust `braintrust-home-scroll1.png`).  
4. **Visible ⌘K search chip** (Langfuse/Braintrust docs) + Ask AI utility icon (1A).  
5. **Narrow tonal sidebar** ~200–240px, section groups, quiet active tick (Helicone product crop).  
6. **Home = decision surface** — status → diagnosis → **one** CTA (fleet north star; Helicone proves metrics-in-fold, Eden does not copy the wall).  
7. **Cookie chrome = zero after choice** (2A; competitors silent).  
8. **Content-local toolbars** for filters/time — don’t grow a second global band.  
9. **Bottom-layer exclusivity** contract (cookie gone + FAB + mobile nav never stack).  
10. **DESIGN density** — 28–32px controls, 14px body, one accent (keep tokens).

### Anti-clone (explicit non-goals)

1. Helicone **6-card KPI collage** as Eden Home first viewport.  
2. Langfuse **dual Ask AI** (bar + button) without exclusivity.  
3. Langfuse **3-column docs portal** as authenticated Home.  
4. Braintrust **royal-blue / pink marketing bands** inside the dark portal.  
5. Helicone **light-blue marketing** aesthetic for authenticated shell.  
6. Laminar **orange “Chat with trace”** brand identity / Trace·Chat·Signals as Eden chrome.  
7. Phoenix marketing **purple glow**.  
8. Restoring Settings **double sidebar** or Home **widget editor**.  
9. Always-on **cookie preferences pill**.  
10. Returning **PageHelpHint / eyebrow location triple**.

### Critic verdict
Prior Waves 1–12 correctly demoted FAB/coach and froze Home — but that created the user pain this fleet exists to fix (“chat gone”, “cookie pill never leaves”). Wave 0 confirms **1A + 2A** against competitor evidence. Proceed to Wave 1 contracts before any product UI.
