# Product

## Register

product

## Users

Agent builders. They open this site to watch wrap runs, review compile requests, and edit a workflow on a canvas before Approve. They are not Claude Code users; the wedge is `wrapTools` plus Eden-hosted wrap.

## Product Purpose

Home is a master-detail workbench: Requests and Issues in a rail, the selected stretch as a pan/zoom canvas. Approve is a human action after editing steps. A runtime key never turns a tool On. Live is the same shell for live and paused tools. Success is: a builder can see a compile candidate, understand the graph, edit it, and ship — or dismiss a refusal with a diagnosis.

## Brand Personality

Night studio. Exact, unhurried, iron. Coral for the one ship action. Ice for live. Not mint, not gold, not lavender.

## Anti-references

Signal Black + gold portal. IBM Plex wireframes. Fraunces highlighter-E. Cream paper. KPI card grids. Neon cyan-on-dark. Linear lavender `#5e6ad2`. Mint / garden / hue 155. Tables as Approve UI. Huge empty heroes. Glassmorphism stacks. Green success.

## Design Principles

1. Home is a dashboard. The canvas is the product surface, not a diagram in a card.
2. Same `logo.webp`. Never redraw the mark.
3. Approve happens on the canvas after editing steps. One chromatic CTA.
4. Flattened chrome: luminance stacking and hairlines, not nested cards or drop-shadow stacks.
5. A runtime key never turns a tool On.

## Accessibility & Inclusion

WCAG AA for body and muted text on bg, canvas, and lift. Reduced motion disables pulse and transitions. Focus-visible rings on the coral accent. Color is never the only state signal (text labels for PASS / FAIL / live / paused).
